## 🌳 SOBRE O PROJETO

Ocarina Online é uma experiência musical interativa
desenvolvida para navegadores, inspirada na estética
visual dos clássicos jogos 3D da era Nintendo 64.

O projeto combina música, cenários tridimensionais,
personagens e animações em um ambiente interativo.

## ✨ FUNCIONALIDADES

- Experiência musical interativa.
- Ambiente tridimensional.
- Personagens animados.
- Cenários em estilo Low Poly.
- Efeitos visuais e sonoros.
- Execução diretamente no navegador.

---

## 💻 TECNOLOGIAS

- JavaScript
- React
- Three.js (se utilizado)
- Modelos 3D em GLB
